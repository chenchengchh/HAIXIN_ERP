# AI 语音模型下载说明

系统前端内置 **AI 语音助手**（基于浏览器录音 → 后端 ASR 识别）。语音功能依赖以下模型，
由于单模型最大约 **840MB**、总体约 **1GB**，超过 GitHub 单文件 100MB 限制，**模型不随仓库分发**，
需按下文手动下载并放置到指定目录。不使用语音功能可跳过本节，不影响系统其他功能。

## 一、模型清单

| 模型 | ModelScope ID | 用途 | 放置目录（相对 frontend/public/models/iic/） |
|------|--------------|------|---------------------------------------------|
| Paraformer 语音识别 | `iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch` | 中文语音识别主模型 | `speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch/` |
| FSMN-VAD 静音检测 | `damo/speech_fsmn_vad_zh-cn-16k-common-pytorch` | 语音活动检测（断句） | `speech_fsmn_vad_zh-cn-16k-common-pytorch/` |
| 时间戳预测 | `damo/speech_timestamp_prediction-v1-16k-offline` | 字级时间戳 | `speech_timestamp_prediction-v1-16k-offline/` |

> 另有小模型 `speech_paraformer-small_asr_nat-zh-cn-16k-common-vocab8404`（约 150MB），
> 为容器内 AI-Voice 服务使用的识别模型，按同样方式下载后放置于 Docker 挂载的模型目录。

## 二、方式一：脚本一键下载（推荐）

```bash
# 1. 安装下载工具
pip install modelscope

# 2. 运行下载脚本（下载 VAD 与时间戳模型）
python scripts/download_voice_models.py

# 3. 主 ASR 模型较大，可单独下载
python scripts/download_timestamp_model.py
```

> 注意：脚本内 `target_root` 默认指向旧机器路径，使用前请将其修改为
> 本仓库实际路径：`<仓库根目录>/frontend/public/models/iic`。

## 三、方式二：Python 手动下载

```python
from modelscope.hub.snapshot_download import snapshot_download

models = [
    "iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch",
    "damo/speech_fsmn_vad_zh-cn-16k-common-pytorch",
    "damo/speech_timestamp_prediction-v1-16k-offline",
]

for m in models:
    snapshot_download(m, local_dir=f"frontend/public/models/iic/{m.split('/')[-1]}")
```

## 四、方式三：网页手动下载

访问 ModelScope 模型页，点击「下载模型」压缩包，解压至对应目录：

- Paraformer-Large：<https://modelscope.cn/models/iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch>
- FSMN-VAD：<https://modelscope.cn/models/damo/speech_fsmn_vad_zh-cn-16k-common-pytorch>
- 时间戳预测：<https://modelscope.cn/models/damo/speech_timestamp_prediction-v1-16k-offline>

## 六、注意事项

1. `.gitignore` 已忽略 `frontend/public/models/` 与 `*.pt`，**请勿**将模型提交到 Git。
2. Docker 部署时，如需容器内使用语音模型，请在 docker-compose 中为 ai-voice 服务
   挂载模型目录（`MODEL_DIR` 环境变量指定的路径，默认 `/app/models/...`）。
3. 浏览器端首次使用语音助手会按需加载 VAD/时间戳小模型；主 ASR 识别在服务端完成。
4. 模型版本更新后，请保持 `model.pt` 与 `configuration.json` 等配套文件来自同一版本。
