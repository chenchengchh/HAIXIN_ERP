# 依赖安装说明

本文档说明运行「海星数字化系统」所需的全部环境依赖与版本要求。

## 一、必备依赖

| 依赖 | 版本要求 | 用途 | 验证命令 |
|------|---------|------|---------|
| JDK | 17+ | 后端编译与运行 | `java -version` |
| Maven | 3.8+ | 后端构建 | `mvn -version` |
| Node.js | 18+（推荐 20 LTS） | 前端构建与开发 | `node -v` |
| npm | 9+ | 前端包管理 | `npm -v` |
| Docker | 24+ | 容器化部署 | `docker -v` |
| Docker Compose | v2（docker 子命令） | 一键编排 | `docker compose version` |

> Windows 用户建议开启 Docker Desktop 的 WSL2 后端；仓库根目录的 `.wslconfig` 可作为参考配置。

## 二、后端依赖构建

父 `pom.xml` 已聚合全部模块，一次构建即可：

```bash
# 在仓库根目录执行（跳过测试加快构建）
mvn clean install -DskipTests
```

主要框架版本（由父 POM 统一管理）：

| 框架 | 说明 |
|------|------|
| Spring Boot | 微服务基础框架 |
| Spring Cloud + Spring Cloud Alibaba | Nacos 服务发现/配置 |
| Spring Cloud Gateway | API 网关 |
| MyBatis-Plus | ORM 与参数校验（JSR-380） |
| MySQL Connector/J 8 | 数据库驱动 |

### 本地方式启动单个服务（调试用）

按顺序启动（本地直跑时 Nacos/MySQL 需已就绪）：

```bash
# 网关
cd src/gateway && mvn spring-boot:run

# 任一业务服务，例如 ERP
cd src/core-services/erp && mvn spring-boot:run
```

> 推荐使用 Docker 编排启动全部服务（见 README 第四节），本地 `mvn spring-boot:run` 仅用于单服务调试。

## 三、前端依赖安装

```bash
cd frontend
npm install          # 安装全部依赖（首次较慢，可配置国内镜像）
```

前端主要依赖：

| 依赖 | 用途 |
|------|------|
| vue 3 / vue-router / pinia | 框架核心与状态管理 |
| element-plus + icons | UI 组件库 |
| vite + @vitejs/plugin-vue | 构建与开发服务器 |
| echarts / echarts-gl | 图表与 3D 可视化（AGV 监控） |
| @antv/g6 | 关系图（供应链可视化等） |
| dhtmlx-gantt | 甘特图（APS 排程） |
| axios | HTTP 请求（已封装统一请求工具 src/api/） |
| tesseract.js | OCR（票据识别等场景） |
| vitest | 单元测试 |

npm 常用脚本：

```bash
npm run dev          # 开发服务器（端口 3000）
npm run build        # 生产构建（vue-tsc 类型检查 + vite build）
npm run preview      # 构建产物预览
npm run test:run     # 单元测试
npm run typecheck    # TypeScript 类型检查
```

## 四、数据库初始化

使用 Docker 编排时**自动完成**：`docker/mysql/init/*.sql` 会在 MySQL 首次启动时按序执行，
自动创建 `hxcoe003` 及各业务服务独立库（`aps_db`、`hr_db` 等）与账号。

手动初始化（非 Docker 环境）：

```bash
mysql -h <host> -P 3307 -u root -proot < docker/mysql/init/00-init.sql
# 再按需执行其余 init 脚本
```

## 六、常见问题

| 问题 | 处理方式 |
|------|---------|
| `mvn` 下载依赖慢 | 在 `~/.m2/settings.xml` 配置阿里云镜像 |
| `npm install` 慢 | `npm config set registry https://registry.npmmirror.com` |
| 端口冲突（3000/9000/3307/8848/6379） | 修改 `.env` 或 docker-compose.yml 中端口映射 |
| MySQL 首次启动失败 | 确认 `docker/mysql/data` 为空（首次启动不要挂载旧数据） |
| 服务注册不上 Nacos | 确认 Nacos healthcheck 通过后再启动业务服务（compose 已编排依赖顺序） |
