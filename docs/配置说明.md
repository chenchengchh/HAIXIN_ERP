# 配置说明

本文档说明系统的各配置文件与环境变量。

## 一、环境变量（.env）

复制模板 `cp .env.example .env` 后按需修改。主要变量：

### 1. 基础设施

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `MYSQL_HOST_PORT` | 3307 | MySQL 宿主机端口（容器内 3306） |
| `MYSQL_ROOT_PASSWORD` | root | root 密码（**生产环境务必修改**） |
| `MYSQL_DATABASE` | hxcoe003 | 默认库 |
| `MYSQL_CHARSET` | utf8mb4 | 字符集 |
| `NACOS_ADDR` | nacos:8848 | Nacos 地址（容器网络内） |
| `NACOS_AUTH_ENABLE` | false | Nacos 鉴权开关 |

### 2. AI 语音

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `VOICE_SERVER_PORT` | 8000 | AI-Voice 服务端口 |
| `MODEL_DIR` | /app/models/speech_paraformer-small... | 容器内 ASR 模型路径 |

### 3. 前端

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `VITE_PROXY_TARGET` | http://localhost:9000 | 开发代理目标（网关） |

## 二、docker-compose.yml

顶层编排文件，分两类服务：

### 1. 基础设施

| 服务 | 端口映射 | 健康检查 |
|------|---------|---------|
| mysql | 3307 → 3306 | `mysqladmin ping`（root/root） |
| nacos | 8848、9848-9849 | `/nacos/actuator/health` |
| redis | 6379 | `redis-cli ping` |

### 2. 业务微服务（每个服务模式相同）

以 APS 为例：

```yaml
aps:
  build:
    context: ./src/core-services/aps   # 以各服务源码 + Dockerfile 构建
  ports:
    - "8087:8087"                      # 宿主机:容器 端口映射
  depends_on:
    mysql: { condition: service_healthy }   # 先等基础设施健康
    nacos: { condition: service_healthy }
  environment:
    - SPRING_PROFILES_ACTIVE=docker          # 激活 docker profile
    - SPRING_DATASOURCE_URL=jdbc:mysql://mysql:3306/aps_db?...  # 服务独立库
    - SPRING_DATASOURCE_USERNAME=aps_app     # 服务独立账号
    - SPRING_CLOUD_NACOS_DISCOVERY_SERVER_ADDR=nacos:8848
```

关键约定：

- **一服务一库一账号**：`{svc}_db` / `{svc}_app`，初始化脚本在 `docker/mysql/init/`
- **跨服务调用**：通过 Nacos 服务名或 compose 服务名互访（如 `ERP_BOM_BASE_URL=http://bom:8085`）
- **端口总览**（宿主机）：网关 9000、AGV 8081、SRM 8082、SCM 8083、PLM 8084、BOM 8085、
  WMS 8086、APS 8087、HR 8088、OA 8089、CRM 8090、ERP 8091、LES 8092、SCADA 8093、
  商机 8094、MES 8095、EAM 8096、AI-Brain 8097、SCRM 8018、QMS 8099、EMS 3108、AI-Voice 8000

## 三、后端服务配置（application.yml）

每个服务 `src/main/resources/application.yml` 按 profile 组织：

| Profile | 场景 | 数据源 |
|---------|------|--------|
| `default`/`local` | 本地开发 | localhost:3307 |
| `docker` | 容器编排 | mysql:3306（compose 注入的环境变量优先） |

优先级：**环境变量（compose 注入）> application-{profile}.yml > application.yml**，
因此容器部署时无需修改任何 yml，全部由 compose 注入。

Nacos 配置导入采用 `optional:` 前缀（`SPRING_CONFIG_IMPORT=optional:nacos:nacos:8848`），
配置中心不可用时不阻塞启动。

## 四、前端配置

| 文件 | 说明 |
|------|------|
| `frontend/vite.config.ts` | 开发服务器端口 3000、`/api` 代理至网关 9000 |
| `frontend/.env.*` | `VITE_*` 前端环境变量（生产构建的 API 基地址等） |
| `frontend/src/api/index.ts` | 统一请求工具：基地址、Token 请求头、code/msg/data 解析、401 跳登录 |

## 五、网关路由

网关（src/gateway）按服务名路由到各微服务，前端仅访问网关统一入口：

```
前端 /api/v1/erp/**  →  网关 :9000  →  lb://erp-service（Nacos 负载均衡）
```

新增服务只需：① Nacos 注册；② 网关增加一条路由；③ 前端 api 目录封装对应接口函数。
